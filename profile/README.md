## 🚀 What is Customizr?

**Team Customizr** makes an AI powered Discord server builder. It lets anyone create a full, professional Discord server in seconds.

No more hours of setting up channels, roles and permissions. Just tell our AI what you want and it builds it for you.

- 🧠 **AI Setup** — Describe your server and get a full setup in seconds
- 🎨 **Full Control** — Channels, roles, categories, permissions and more
- ⚡ **Fast Setup** — Go from idea to live server in one click
- 🔒 **Safe and Reliable** — Built using Discord best practices
